## Failure cases

- untrusted remote IPC sender rejected;
- non-HTTPS/non-chess.com theme navigation rejected;
- popup requests denied;
- permission requests denied;
- secret storage unavailable/basic-text fallback rejected;
- missing Claude key rejected in main process;
- theme load/CSS insertion fails soft;
- invalid/illegal practice move remains handled by the core boundary.

## Known limitations

- Actual renderer/preload/window behavior needs one run on a desktop display.
- Real safeStorage requires the user's OS keychain/keyring.
- The full puzzle corpus must be generated separately and placed in the user-data directory or selected with `CHESS_PUZZLE_DB_PATH`.
- Visual theme tokens/assets are completed in M6; M5 uses a minimal placeholder chess.com CSS skin.
