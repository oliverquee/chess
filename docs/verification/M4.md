## Security/code-path audit

Application modules were searched (excluding vendored Stockfish) for DOM,
querySelector, webContents, executeJavaScript, active/current game, and board
state readers. No implementation match was found. Network-origin inspection
found only Anthropic, localhost Ollama, and the read-only chess.com PubAPI
origin. The chess.com constructor contains only the complete monthly archive
path.

The current official Chess.com PubAPI documentation describes that path as the
array of games a player has finished and separately documents current-game
routes; this implementation does not implement or reference those routes.
