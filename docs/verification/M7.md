## Known limitations & PENDING verifications

1. **Native SQLite Plugin Bridge:** Verified with Promise-based async test contract in Node. Full end-to-end execution on an active Android/iOS emulator requires native SDK build toolchains (`npx cap run android` / `npx cap run ios`). Marked honestly as PENDING.
2. **App Store / Play Store Packaging:** Requires Xcode and Android Studio compilation and signing. Marked PENDING.
3. **Chess.com In-App Browser Live Theme Injection:** Selectors are documented based on Chess.com's responsive web component DOM. Live WebView injection on mobile device will be exercised during device QA.
