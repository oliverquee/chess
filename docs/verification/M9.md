## Chess.com fair-play boundary

The Chess.com tab is a visual skin only. It does not read board state, scrape
positions, expose DOM content to the host app, run Stockfish, show future
moves, or provide any analysis or assistance during Chess.com gameplay. Its
only `executeScript` payload installs the bundled CSS in a guarded style
element. Live emulator evidence confirmed the current image-backed
`wc-chess-board.board` selector and the cream/cinnamon replacement. A later
repeat load reached Chess.com's Cloudflare verification page, so authenticated
login persistence remains unclaimed.

## Browser storage limitation

The browser preview uses a clearly marked dev-only adapter generated under the
ignored `artifacts/browser-preview` directory. It is never loaded by
`www/index.html` and was generated only after the release APK sync. Its
browser-local setting persistence is layout/interactivity evidence only and
does not prove the native SQLite plugin works.
