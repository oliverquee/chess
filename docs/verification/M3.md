## Failure cases

- malformed JSON;
- fenced recoverable JSON;
- invalid category;
- missing severity;
- prose-only output;
- second validation failure;
- HTTP/backend unavailable;
- invented puzzle ID;
- invented evidence count;
- historical model result replaced as current without double-counting.
