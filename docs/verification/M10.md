## 1. Summary of Changes

Milestone M10 upgrades Cat Analyst with full freeplay practice capabilities, calibrated Stockfish cat personas, drift-proof chess clocks, progressive on-demand hints, a win-probability eval bar, seed round scoring, anti-gaming streaks with monthly freezes, category mastery progression with 14-day decay, and SQLite database backup/restore.

### Key Architectural Invariants Enforced:
1. **Strict Surface Separation:**
   - **Chess.com InAppBrowser Surface:** Absolute zero assistance. No board scraping, no eval bar, no hints, no move suggestions. Pure theme CSS injection only.
   - **Offline Local Practice Surface:** Training tool against local Stockfish 18 Lite WASM. Assistance allowed on-demand.
2. **Actual Usage Assistance Filtering:**
   - Every game records runtime `assistance_level` (`none`, `preview`, `hints`, `full`) calculated dynamically from actual player actions (`hint_count`, `takeback_count`, `preview_used`).
   - Weakness profile queries (`getWeaknessTally`) strictly filter `WHERE g.assistance_level = 'none'`, preserving statistical validity.
3. **Calibrated Stockfish UCI Parameters:**
   - Accounted for Stockfish 18 Lite's hard `UCI_Elo` floor of 1320.
   - Below 1320 (`kitten`, `tabby`): Uses `Skill Level` (0, 3) + clamped search depth (1, 4).
   - Above 1320 (`alley_cat`, `hunter`, `panther`): Uses `UCI_LimitStrength = true`, `UCI_Elo` (1500, 1800, 2100) + depth limits (8, 12, 16).
   - `apex_tiger`: Full unconstrained Stockfish (`UCI_LimitStrength = false`, Skill Level 20).

### B. Stockfish Personas & Practice Engine
- **`engine/stockfishWorker.js`**:
  - Configured `PERSONAS` dictionary with exact Elo/Skill Level/depth parameters.
  - Dynamically switches UCI options on every `playMove(fen, personaOrSkillLevel)`.
- **`engine/clock.js`**:
  - Implemented `ChessClock` with `STANDARD_TIME_CONTROLS` (`1|0`, `3|0`, `3|2`, `5|0`, `10|0`, `15|10`, `none`).
  - Timestamp-delta elapsed time calculation (`Date.now()`) preventing drift on lag and background pause/resume.
- **`engine/practiceSession.js`**:
  - Added freeplay unseeded session support, custom starting FENs, player color selection.
  - Added in-game actions: `takeback()` (reverts move pair, resyncs FEN), `offerDraw()` (accepts if $|cp| \le 75$), `resign()`.
  - Added runtime assistance logging: `recordHint(tier, detector)`, `recordPreview()`, and `computeAssistanceLevel()`.

### C. Progressive Hints & Win-Probability Eval Bar
- **`engine/hints.js`**:
  - **Tier 1 (Warm):** Static Exchange Evaluation / hanging piece detector without revealing move destinations.
  - **Tier 2 (Warmer):** Null-move threat search (detecting opponent's immediate multi-move tactics).
  - **Tier 3 (Hot):** Best-move nudge indicating active piece and target square.
  - **Blunder Confirmation Gate:** `checkBlunderCandidate` intercepting moves with eval drops $\ge 200$ cp or mate threats.
- **`engine/evalBar.js`**:
  - Implemented Lichess sigmoid winning probability formula:
    $$\text{winPercent}(cp) = 50 + 50 \times \left( \frac{2}{1 + \exp(-0.00368208 \times cp)} - 1 \right)$$
  - Handles mate sentinel scores ($100\%$ / $0\%$) and numerical centipawns (+1.5, -0.8).

### D. Scoring, Streaks & Mastery Progression
- **`core/scoring.js`**:
  - Seed round scoring formula:
    - **Accuracy (60%):** Weighted move accuracy based on eval delta drops.
    - **Motif (30%):** Tactical resolution and advantage preservation.
    - **Hint Penalty (-10%):** Up to -30 pts deducted per hint used.
    - Letter grade calculation (A+, A, B, C, D).
- **`core/streaks.js`**:
  - Anti-gaming daily floor (requires completing target $N=3$ sessions per day).
  - Monthly 2 streak freezes (`freezesRemaining`).
  - Category mastery levels 0–5 with 14-day inactivity decay.
